# 大脑图绘制对象释放

状态：实现及验证中，未发布。

用户验收：加载全过程保持响应；loading 消失前数据、布局和视口绘制已完成；立即可编辑、标记和平移；最后末级节点可见且可点击，之后继续监测至少 15 秒。保持现有交互、后端协议、结果与历史折叠状态。

证据：50000 末级节点的延长观察测试捕获 1322ms MajorGC；屏外 display:none 未释放 SVG 及 renderer 对象。原测试加载后只观察 100ms，覆盖不足。

边界：只改脑图前端渲染层。复用现有 renderer、连接线及样式；不更改颜色、布局算法、数据模型、数据库或 Socket。用例节点和布局尺寸全量保留，屏外 renderer 图形及引用释放；进入视口时复用原 renderer 重建。首轮测量后立即释放，避免先积累全量图形再集中回收。

架构结论：有条件通过。必须验证释放不会损坏布局、选中、展开按钮、Camera、SVG 导出、删除和替换导入。小图沿用原渲染路径。初版保留空节点容器及连接线，重复测试仍出现 644ms 停顿；最终连同屏外容器和连接线一起释放，节点容器按需恢复，逻辑节点与布局矩阵继续保留。

步骤：
1. 将性能观察延长到 15 秒，加入活跃 renderer 数门禁，确认旧版失败。
2. 加入可逆图形释放与视口恢复；测量结束分批释放，不留全量 renderer 峰值。
3. 测试原布局/数据不变、远节点与导出完整；50k 编辑和执行性能测试。
4. 浏览器实际页面验收、生产构建、评审、提交推送和 Windows 打包。未达标不得宣称完成或发布。

恢复：仅回退本轮前端改动，不改用户数据。当前正式服务保持不变，测试在独立隔离浏览器执行。
